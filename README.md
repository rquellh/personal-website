# Personal Website

A nostalgic trip back to the computer of my youth. This is my personal portfolio site dressed up as a Windows 95 desktop — complete with draggable windows, a taskbar, and all the pixelated charm I grew up with.

Built with [Astro](https://astro.build), [React](https://react.dev), and [React95](https://react95.io).

## Commands

| Command         | Action                                |
| :-------------- | :------------------------------------ |
| `npm run dev`   | Start dev server at `localhost:4321`  |
| `npm run build` | Build production site to `./dist/`    |
| `npm test`      | Run tests                             |
